# Team Lead Manager v4 — No DOB Ranges

DOB range sorting and DOB menus have been removed.

Current lead behaviour:
- Every non-empty line in an uploaded file = one lead.
- Admin uploads file, then enters FILE NAME.
- PICKED / NO ANSWER / RAN / INVALID.
- NO ANSWER returns to retry pool.
- RAN and INVALID permanently close the lead.
- NEW LEAD button sends the next lead.
- PICKED -> Upload Notes -> READY FOR WA / RAN.
- READY FOR WA keeps the clean group formatting.
- TAKE FURTHER sends the full lead privately to the admin who clicks it.
- Worker approvals, /setgroup, /remove, /stats, /workers, /export and /reset remain.
